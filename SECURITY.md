# Security

Please do not disclose security vulnerabilities, exposed credentials, privacy incidents, or approval-bypass flaws in a public GitHub issue.

Use GitHub's private vulnerability reporting for this repository if it is enabled, or contact the repository owner privately through GitHub. Include reproducible steps, affected commit or deployment, impact, and a safe way to reach you. Do not include real resumes, inbox exports, tokens, or other personal data in the report.

For development:

- use synthetic fixtures;
- keep secrets out of Git and logs;
- follow the controls in [docs/SECURITY-PRIVACY.md](docs/SECURITY-PRIVACY.md);
- report suspected application-submission or email-send bypasses as security issues, not ordinary feature requests.
